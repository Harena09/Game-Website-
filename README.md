# Game-Website-
   This is a 2D car online game project, a basic responsive website built to get familiar with HTML, CSS, and Javascript and MongoDB CRUD functionality. This game consists of controlling the main car to avoid dodging the enemy cars, earn points based on the timer, and make it to the highest in the rank.  This is part of a university project to learn basic web development, Javascript logic, and data storage. 

  # Technology used

 - HTML 
 - CSS
 - Javascript
 - MongoDB
