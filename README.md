# Game-Website-
   This is a 2D car online game project, a basic responsive website built to get familiar with HTML, CSS, and Javascript and MongoDB CRUD functionality. This game consists of controlling the main car to avoid dodging the enemy cars, earn points based on the timer, and make it to the highest in the rank.  This is part of a university project to learn basic web development, Javascript logic, and data storage. 

  # Technology used

 - HTML 
 - CSS
 - Javascript
 - MongoDB
 - Local and Session storage

# Features 
- Sign up and Login system
- input validation using Javascript
- 2D car game with keyboard controls
- Enemy cars with random movement
- Collision detection
- Score tracking
- Leaderboard (ranking table)
- Data stored in browser Local Storage

# How the game works

1. Play creates an account and log in
2. press Start to begin the game
3. play's car increases speed
4. enemy cars appear
5. the goal is to survive as long as possible
6. if collison happens, the game ends
7. player's score is shown on the leaderboard

# Data Storage 
- User details are stored in local storage
- score is stored in a array of objects in JSON format
- using Javascript sorting algorithm to classify scores in descending order
- the leaderboard updates automatically

What I learned: 

- How to build a complete multi-page website
- How to use JavaScript for game logic and animations
- How to handle keyboard input and event listeners
- How to validate forms using JavaScript and Regular Expressions
- How to store and retrieve data using Local Storage
- How to sort and display dynamic data in a leaderboard

# How to run the project

- clone the repo
- open the project folder
- open the index.html and create an account
